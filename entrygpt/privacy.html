이 안내는 kkomaweb.com 명의로 배포되는 “엔트리 작품 제작 AI”의 현재 스킬 전용 패키지와 이 안내 사이트에 적용됩니다.

1. 플러그인의 데이터 처리 범위

현재 패키지는 제작 지침과 참고 자료를 제공합니다. 개발자가 운영하는 별도 데이터 수집 서버, 외부 MCP 서버, 자동 음성 전사 서버는 연결되어 있지 않습니다. 패키지 자체에는 대화·업로드 파일을 개발자 서버로 전송하거나 저장하는 기능이 없습니다.

2. ChatGPT에서 제공하는 내용

ChatGPT에 입력하는 작품 설명, 대화와 첨부 파일은 ChatGPT 서비스에서 처리됩니다. 그 처리와 보관·삭제·공유·모델 개선 설정에는 OpenAI의 정책과 사용자의 계정 설정이 적용됩니다. 이 안내가 OpenAI의 정책을 대체하거나 별도의 보관 기간을 정하지는 않습니다.

3. 이 안내 사이트

이 사이트에는 회원가입, 문의 접수, 파일 업로드, 결제 양식, 광고 또는 별도 방문 분석 스크립트를 넣지 않았습니다. 페이지를 제공하는 호스팅·네트워크 사업자는 요청 처리와 보안을 위해 IP 주소 등 접속 정보를 처리할 수 있으며, 해당 사업자의 정책이 적용됩니다.

4. 지원 문의

오류 신고는 GitHub 저장소의 공개 이슈로 접수할 수 있습니다. 작성한 내용과 GitHub 계정 정보는 GitHub에서 공개될 수 있습니다. 비밀번호, 토큰, 개인정보나 비공개 작품 파일을 게시하지 마세요. 공개 이슈의 수정·삭제와 보관에는 GitHub의 기능과 정책이 적용됩니다.

5. 개인정보 관련 도움

이 패키지 자체의 별도 사용자 데이터 저장소는 없습니다. ChatGPT에 저장된 데이터의 확인·삭제·설정 변경은 OpenAI의 개인정보 안내와 공식 도움말에 있는 요청 경로를 이용하세요. 작품에 불필요한 개인정보나 비밀 정보를 포함하지 마세요.
