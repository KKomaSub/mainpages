사용 중 막혔나요?

아래 안내에서 문제에 맞는 해결 방법을 확인하세요.

GitHub에서 오류 신고·문의하기

문제가 생긴 순서, 기대한 결과, 실제 결과와 오류 메시지를 적어 주세요. 문의는 공개되므로 비밀번호·토큰·개인정보·비공개 파일을 올리지 마세요. GitHub 로그인이 필요합니다.

.ent 파일을 불러올 수 없어요

다운로드한 파일이 실제 .ent 파일인지 확인하고, 엔트리 편집기의 작품 파일 불러오기 기능을 사용하세요. 계속 실패하면 같은 ChatGPT 대화에 오류 메시지와 파일을 첨부해 “tar 구조와 temp/project.json을 확인해서 수정해 주세요”라고 요청하세요. 민감한 내용은 먼저 제거하세요.

이미지나 소리가 보이지 않아요

원본 파일이 작품에 포함되지 않았거나 JSON의 에셋 경로가 일치하지 않을 수 있습니다. 사용 권한이 있는 원본 자료와 함께 “이미지·썸네일·사운드 파일의 실제 포함 여부와 경로를 확인해 주세요”라고 요청하세요.

작품이 실행되지 않거나 블록이 이상해요

발생 순서, 기대한 동작, 실제 동작과 오류 메시지를 알려 주세요. “블록 종류, 오브젝트·장면 ID, 함수 매개변수와 장면 시작 흐름을 확인해 주세요”라고 요청하면 문제 범위를 좁힐 수 있습니다. 수정 전 원본은 따로 보관하세요.

음원을 올렸는데 단어별 타이밍을 만들지 못해요

이 패키지에는 자동 전사 서버가 없습니다. 현재 환경에 실제 오디오 분석 도구가 없다면 단어별 시작·끝 시각 자료를 제공해야 합니다. 문장 길이나 BPM만으로 계산한 시각을 실제 분석 결과로 취급하지 않습니다.

다운로드 링크가 열리지 않아요

파일을 만든 대화에서 파일을 다시 생성해 달라고 요청하세요. 파일 이름만 표시된 답변은 실제 파일이 아닐 수 있습니다. 생성된 다운로드 링크를 이용하세요.

개인정보나 ChatGPT 계정 관련 도움이 필요해요

플러그인 관련 문의는 위 GitHub 오류 신고 링크를 이용하세요. 이 안내 사이트 자체는 문의나 파일을 저장하지 않습니다. ChatGPT에 저장된 대화·업로드 파일·계정의 처리와 삭제는 OpenAI의 공식 지원 및 개인정보 요청 경로를 이용하세요.
